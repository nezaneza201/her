# Queen ❤️

A one-page romantic proposal and long-distance relationship promise letter.

## What is inside

- Romantic opening screen
- Animated floating hearts and glowing background
- Personal love letter
- Promises from him
- Promises requested from her
- Long-distance relationship section
- Communication, time, loyalty, respect, softness and trust
- Responsive mobile design
- No forms, databases, APIs, email services, or environment variables

## Deploy

This is a simple Next.js site and can be deployed directly to Vercel from GitHub.
